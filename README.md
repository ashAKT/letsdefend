# LetsDefend

This repository is currently a placeholder for LetsDefend-related cybersecurity learning, SOC investigation exercises, and defensive security notes.

## Suggested organization

As you add work, consider organizing it by lab or investigation:

```text
letsdefend/
├── README.md
├── alert-investigations/
├── incident-reports/
├── threat-hunting/
└── screenshots/
```

For each exercise, document the alert or scenario, investigation steps, relevant evidence, conclusion, and lessons learned. Remove or redact credentials, tokens, personal information, and sensitive environment details before publishing.
